# Clustering

Explanation, discussion, simulations, and comparisons of clustering methods.

This is intended to be the first in a series of different clustering methods. Sam wrote the notes while employed as an actuarial analyst, in a role that used these measures, in support of human rights and the rights of U.S. citizens against algorithmic bias and discrimination. The stance is posted under this site: https://sdcastillo.github.io/Clustering/what-i-stand-for/
